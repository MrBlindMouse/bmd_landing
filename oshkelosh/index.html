Oshkelosh

Modular e-commerce you host yourself

An open shop platform you run on your infrastructure — not a hosted SaaS.

Customers browse a storefront SPA; you manage catalog and orders in a built-in admin. Plug in payments, print-on-demand suppliers, and customer messaging from separate addon packages on GitHub.

You choose providers and frontends; the core stays a small, orchestrated commerce engine.

GitHub organization · Quick start

Platform

Composable storefront

Swap frontend addons — bring your own SPA or start from the reference Svelte storefront in the org. One active theme at a time, served from the core.

Admin included

Manage products, variants, orders, and manual suppliers. Install addon packages from a ZIP or URL when you are ready to extend.

Checkout you control

The core runs cart and order lifecycle; payment addons talk to Stripe, PayPal, and other processors through a single checkout seam.

Catalog and fulfillment

Listings and sellable SKUs stay separate. Route line items to Printful, Gelato, manual suppliers, and more — several suppliers can coexist on one shop.

Addon ecosystem

Each integration is its own repository under github.com/Oshkelosh. Enable one payment processor at a time; email, SMS, and push each use one active provider per channel. Install via the admin dashboard after deploy.

About

Oshkelosh is for merchants and developers who want a real storefront under their own domain and keys — without renting a platform that locks in payments, themes, and fulfillment.

The shape is deliberately modular: core commerce stays predictable, while Stripe vs Mollie, Printful vs Gelato, and Postmark vs Resend are choices you install rather than code you fork. It is not trying to be every hosted shop-builder; it is an open engine you can own.
